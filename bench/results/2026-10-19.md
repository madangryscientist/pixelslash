# PixelSlash vs Argos, 2026-10-19

56 labelled pairs (31 real, 20 noise, 5 identical) from `bench/corpus/`, each scored the same way for both tools. `bun run bench` reproduces this; `bench/README.md` says how it is measured.

- PixelSlash: `bfe2d4a`, `diffPngs` as it is (exact pixels, no tolerance, no anti-aliasing detection). It reports a count and an overlay, not regions: regions are extracted from the overlay for both tools by the same code.
- Argos: `21e8520c28129d501b22028a5499546b03336e38`, `diffImages` at threshold 0.5, in VM 101 (ops/argos-bench). Its time is `diffImages` alone, without ssh, tar or container start; the whole run, those included, took 5.8 s.
